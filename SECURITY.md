# Security Policy

## Supported Versions

| Version | Supported |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| 0.1.x   | :white_check_mark: |
| 0.1.5   | :x:                |
| 0.1.0   | :x:                |

## Reporting a Vulnerability

Please report any security vulnerabilities by opening a private security advisory or contacting the maintainers directly via email.
